# Quiz App

An interactive quiz application built with HTML, CSS, and JavaScript. Test your knowledge, answer multiple-choice questions, track your progress, and try to achieve a high score.

## Live Demo

**[Play the Quiz App](https://yousef-ashraf-7.github.io/Quiz-App/)**

## Features

* Randomly selected questions.
* Multiple-choice answers.
* Automatic score calculation.
* Countdown timer.
* Question progress tracking.
* High scores saved using Local Storage.
* Separate pages for the home screen, quiz, and high scores.
* Simple and user-friendly interface.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## Project Pages

* **Home Page:** Start the quiz or view high scores.
* **Quiz Page:** Answer questions, track progress, and manage your time.
* **High Scores Page:** View saved quiz scores.

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Yousef-Ashraf-7/Quiz-App.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Click the Play button to start the quiz.
